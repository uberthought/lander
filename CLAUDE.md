## Project Overview

Deep Reinforcement Learning agent for the **LunarLander-v3** Gymnasium environment (continuous action space).

- **`actor.py`** — `ActorModel`. Single scalar full-Q head per `(state, action)`. Trained against a target-network-bootstrapped, potential-shaped target (see below). Smooth L1 (Huber) loss.
- **`world.py`** — `WorldModel`. Predicts the next-state delta from `(state, action)`. Huber loss with `WORLD_LOSS_DELTA`. Used to roll out imaginary episodes for actor training.

All Python lives flat at the project root — no packages. Imports are bare module names (`from observation import …`, `from actor import ActorModel`). Run scripts from the project root.

Shared library modules (imported by the entrypoints; not run directly):
- **`env.py`** — the single home for the discrete-0-3 ↔ continuous-Gymnasium boundary: `ACTION_VECTORS` mapping, `step_action` (does done-folding + 13-dim state assembly), `reset_state` (initial padding), `make_env`.
- **`observation.py`** — `Observation` namedtuple, `calculate_reward`, `is_done_state`, `clip_state`, `create_observation`, and the clip/normalization constants.
- **`rollout.py`** — `run_imaginary_episode`: steps the `WorldModel` under the actor policy to generate synthetic episodes.
- **`metrics.py`** — world-model SNR (`compute_world_value_snr`, per-dim SNR), `actor_stats_str`, and the combined live-report line `print_snr`. Shared so training scripts depend on a library, not on each other.
- **`live_plot.py`** — optional matplotlib live plotting of SNR/actor metrics.

Training / evaluation entrypoints, all sharing the same `ReplayBuffer`:
- `actor_training.py` — on-policy collection loop: actor picks actions, transitions land in the buffer, actor trains every `--train-every` episodes.
- `offline_training.py` — pure replay-buffer training of the actor (no env stepping).
- `world_training.py` — trains the actor on imaginary rollouts generated by the world model, then optionally evaluates in the real env. Flags: `--seconds`, `--rollout-steps`, `--eval-episodes`, `--sample-size`.
- `live_world_training.py` — on-policy variant that trains the actor against world-model rollouts seeded by recent real transitions. Flags: `--seconds`, `--train-every`.
- `live_training.py` — variant of `actor_training.py` (older / alternative live-training entrypoint with the same `--seconds` / `--train-every` flags).
- `play_actor.py` — evaluation: loads a checkpoint, runs `--episodes` episodes, records MP4s under `--video-folder` (default `./videos`). Default checkpoint is `ACTOR_WORLD_MODEL_PATH` (`checkpoints/actor_model_world.pt`).
- `world_horizon_eval.py` — rolls the world model forward against real episodes and writes per-horizon dynamics error to a CSV. Flags: `--episodes`, `--horizon`, `--stride`, `--output` (default `world_horizon_eval.csv`).

## Common Commands

```bash

```

## Architecture

### State & Action Space

- **State**: 13-dimensional vector laid out as `[x, y, vx, vy, angle, vangle, left_leg, right_leg, done, prev_a0, prev_a1, prev_a2, prev_a3]`. The first 6 are continuous sensors (`CONTINUOUS_STATE_DIM = 6`); legs and done are 0/1; the last 4 are a one-hot of the action that produced this state. The initial state after `env.reset()` is padded with `[0, 1, 0, 0, 0]` (legs=01, done=0, prev-action=null).
- **Actions**: flat 4-action discrete space (`POSSIBLE_ACTIONS = 4`). Mapping in `env.ACTION_VECTORS` / `env.step_action` — `0=off`, `1=right`, `2=left`, `3=reverse` — encoded as a 2-D continuous LunarLander action vector.
- Actions are **one-hot encoded** into a 4-dim vector for network input.

### Neural Network Design

```
Input: state (13) + action (4) — projected separately and summed
       Linear(13, 256) + Linear(4, 256)  →  Σ
            ↓
       32× SkipBlock(256)        (LAYER_COUNT × NODE_COUNT)
            ↓
       Linear(256, out_dim)
```

`SkipBlock`: Linear → LeakyReLU → Linear → (+ residual) → LeakyReLU. Optimizer: AdamW.

Output dims by model:
- `actor.py` `ActorNet`: `1` — scalar full Q-value
- `world.py` `WorldNet`: `STATE_SIZE` (13) — predicted next-state delta added back to the input state in `predict_batch` (`world.py:131-139`)

### Reward (`observation.calculate_reward`)

Not the LunarLander default reward. The reward used everywhere here is geometric and dense:

1. Clip the 6 continuous sensors to `CLIP_MIN/CLIP_MAX` (in-flight envelope).
2. Normalize by `[1, 1.75, 4, 4, π, 5]`, take `1 - |·|`, clamp to `[0, 1]`.
3. `position = ‖(x, y)‖₂ / √2`, `other = ‖(vx, vy, angle, vangle)‖₂ / √4`.
4. **Landing bonus**: when `|x| < 0.3`, engines off (`prev_a0 > 0.5`), and a leg flag is set, add `0.5` per leg to `other`.
5. Return `position * other`.

Done states (`observation.is_done_state`): `|angle| > π/2`, `y < -0.5`, `y > 2.0`, or both legs touching down. Treated as done **in addition** to gym's `done`/`truncated`; the `done` flag in the 13-dim state vector is set from this combined condition. `actor_training.py` exits on `done` alone — there is no separate `truncated` branch any more.

### Potential-shaped Q target (ActorModel)

ActorModel predicts full Q directly and bootstraps off its own next-state max:

```
target_full_Q = r(s₁) + [γ · r(s₁) − r(s₀)] + γ · max_a' Q(s₁, a')   # non-terminal
target_full_Q = r(s₁)                                                # terminal (done flag set)
```

with `DISCOUNT_FACTOR = 0.97` (`configuration.py`, read into `self.discount_factor` at `actor.py:50`). The reward function stays explicit on the `s₁` side; the bootstrap absorbs the shaping potential `γ·r(s₁) − r(s₀)`. Loss is Smooth L1 / Huber via `F.smooth_l1_loss(pred, target)` (`actor.py:144`).

**Target network.** `ActorModel` keeps a frozen `target_model` updated by Polyak averaging with `TAU = 0.05` (`configuration.py`) after every gradient step (`actor.py:57-63, 149-150`). The `max_a' Q(s₁, a')` term above is evaluated against `target_model`, not the online net (`actor.py:103, 133`).

### World model (`world.py`)

`WorldModel` shares the SkipBlock trunk with the actor but splits its 13-dim output by format:

- `output[:, :6]` is a **continuous delta** added back to the input state. Loss: `nn.HuberLoss(delta=WORLD_LOSS_DELTA)` (`world.py:64`).
- `output[:, 6:13]` is **logits** predicting the next-state boolean dims (legs `[6:8]`, done `[8]`, prev-action one-hot `[9:13]`) directly — not a delta. Loss: `nn.BCEWithLogitsLoss()` (`world.py:65`).
- Total: `cont_loss + BOOL_LOSS_WEIGHT * bool_loss` (`world.py:108-111`).

The leg-flip / done-fire filter (`world.py:88-90`) applies to the **continuous loss only**: collision impulses corrupt velocity targets but the bool head specifically needs flip transitions to learn them. The bool loss is taken over the entire batch.

`predict_batch` returns `[state[:6] + delta_cont, sigmoid(logits)]` concatenated. Downstream consumers that need hard 0/1 should threshold themselves; `rollout.run_imaginary_episode` overwrites `[6:13]` anyway. The load-bearing consumer of the bool dims is `calculate_reward` reading leg flags.

Default checkpoint path: `checkpoints/world_model.pt`.

### Storage

`ReplayBuffer.py` — `data/replay_buffer.dat`, memmap, ~369 MB, capacity 2²², atomic metadata. Used by every training script.

### Live training on-policy mixing

`actor_training.py` maintains a short-horizon `deque(maxlen=RECENT_BUFFER_SIZE)` of recent transitions alongside the persistent `ReplayBuffer`. Each training cycle (every `--train-every` episodes) mixes `len(recent) * REPLAY_SAMPLE_MULTIPLIER` random samples from the main buffer with **all** recent samples, biasing toward fresh on-policy data (no CLI flag for the multiplier). The inner training loop is wall-clock-budgeted to 10 seconds per cycle.

Per-cycle output is one line via `metrics.print_snr` (`Iter t=Xs Actor-Q SNR=… pred=… tgt=…`); it builds on `metrics.actor_stats_str` to keep that format identical across scripts. The recent-buffer size and replay multiplier are `RECENT_BUFFER_SIZE` (40000) and `REPLAY_SAMPLE_MULTIPLIER` (4) in `configuration.py`.

### Configuration (`configuration.py`)

| Constant | Value | Meaning |
|----------|-------|---------|
| `STATE_SIZE` | 13 | 6 sensors + 2 leg flags + done + 4 one-hot prev action |
| `CONTINUOUS_STATE_DIM` | 6 | First-N dims that go through clipping/normalization |
| `POSSIBLE_ACTIONS` | 4 | Flat discrete action count |
| `LAYER_COUNT` | 32 | Number of `SkipBlock`s in the trunk |
| `NODE_COUNT` | 256 | Hidden width |
| `WORLD_LOSS_DELTA` | 1.0 | Huber-loss `delta` for `WorldModel` continuous head |
| `BOOL_LOSS_WEIGHT` | 1.0 | Multiplier on the BCE term in `WorldModel`'s total loss |
| `DISCOUNT_FACTOR` | 0.97 | Actor Q-learning discount factor γ |
| `TAU` | 0.05 | Polyak averaging rate for `ActorModel.target_model` |
| `ACTION_SHARPENING` | 100 | Softmax temperature multiplier in `get_best_action` |
| `WORLD_LR` | 0.001 | AdamW learning rate for `WorldModel` |
| `DONE_THRESHOLD` | 0.9 | Predicted done-flag value above which an imagined episode terminates |
| `VALIDATION_SAMPLE_SIZE` | 2¹⁰ | Sample drawn for live SNR/metric reporting |
| `RECENT_BUFFER_SIZE` | 40000 | `deque(maxlen=…)` of recent on-policy transitions |
| `REPLAY_SAMPLE_MULTIPLIER` | 4 | Main-buffer samples drawn per recent sample each train cycle |

Checkpoint paths also live in `configuration.py`: `ACTOR_MODEL_PATH` (`checkpoints/actor_model.pt`, actor trained on real transitions), `ACTOR_WORLD_MODEL_PATH` (`checkpoints/actor_model_world.pt`, actor trained on world-model rollouts), `WORLD_MODEL_PATH` (`checkpoints/world_model.pt`).

The actor optimizer uses AdamW defaults; `WorldModel` uses AdamW with `lr=WORLD_LR`.

### Conventions

- **Device**: auto-selects MPS (Apple Silicon) → CPU fallback. Models, tensors, and loaded checkpoints all `.to(self.device)`; loading from a checkpoint saved on a different device requires `map_location`.
- **Action sampling** in `get_best_action`: `softmax(softmax(full_q) * ACTION_SHARPENING)` then `multinomial` — a sharpened temperature trick that's near-greedy but keeps exploration alive.
- **Validation metric**: SNR (dB) per dim = `10·log10(signal / noise)` over the masked validation sample — higher is better dynamics accuracy.
- **Observation namedtuple**: `Observation(prev_state, action, next_state)` — `action` is a single int 0–3, not a tuple.
- **Atomic writes**: every persistent artifact (replay buffer metadata, model `.pt`) writes to a temp file then `os.replace()`s into place. Never write directly to a final path.
- **Checkpoint format**: `{'model_state_dict': ..., 'optimizer_state_dict': ...}`. Loaders handle both this dict form and a bare state-dict for backward compat. When loading optimizer state, the model must be `.to(device)` *before* `optimizer.load_state_dict(...)` so optimizer state lands on the same device as the parameters.
